# Harmony Splitter

utilizando a lovable ai crie um web app com a funcionalidade de speeter de music, atuando como separador de faixa de musicas mediante ao upload de "mp3 " enviados pelo usuários. 
- interface moderna , intuitiva e dinâmica
- o armazenamento deve ser no localstorage (sem supabase)
- se baseie (tenha como referencia) os aplicativos: Moises app e BandLab 
- de uma música , separar faixas de instrumentos, deixando isolados dos demais ou acentuando  o mesmo dentro de uma música 
- sliders de reprodução devem estar presentes em cada faixa de instrumento (apenas voz, baixo, bateria e violao/guitarra) e no repodutor da musica geral 
- deve conter o botão de baixar musica  apóso usuario ter finalizado a maniplação
